ROGITHA G — PORTFOLIO

Files:
- index.html — main portfolio page
- styles.css — styling and responsive layout
- script.js — scroll reveal, cursor glow and mobile menu
- assets/rogitha-workspace.png — portfolio hero image
- assets/rogitha-logo.svg — custom RG logo + favicon
- assets/Rogitha_G_Resume.pdf — one-page resume linked to the Resume buttons

To run locally:
1. Open index.html in a browser, or use VS Code Live Server.
2. For GitHub Pages, upload the complete folder contents to the repository root.
3. Keep the assets folder in the same location so the image, logo and resume links work.

The resume is the one-page FlowCV version supplied for the portfolio and is linked from both the navigation Resume button and the hero Download Resume button.
